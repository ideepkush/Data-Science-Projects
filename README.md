# Data Science Projects

Coursework and practice projects from my MSc in Data Science at the University of Naples Federico II, plus self-study notebooks.

For standalone, production-style projects, see my [pinned repositories](https://github.com/ideepkush).

---

## Larger projects

| Project | What it is |
|---|---|
| [Spark + Kafka sentiment streaming](big-data-spark-kafka/) | Real-time 3-class tweet sentiment with Spark Structured Streaming, Kafka, and Spark NLP. 333 streaming micro-batches, 67% mean accuracy. Also a standalone repo: [spark-kafka-sentiment-streaming](https://github.com/ideepkush/spark-kafka-sentiment-streaming). |
| [A/B testing: Cookie Cats](ab-testing/) | Retention analysis of a mobile-game gate change on the Cookie Cats dataset. |
| [Bank marketing classifier](MachineLearningProjects/Bank-Marketing/) | Term-deposit subscription prediction on the UCI bank marketing dataset. |
| [Statistical modeling study](MachineLearningProjects/A-Statistical-Modeling-Study/) | Poisson vs Exponential model comparison. |
| [Bank marketing EDA](MachineLearningProjects/EDA-Bank-Marketing-Dataset/) | Exploratory analysis of the same dataset. |
| [Regression assignment](MachineLearningProjects/Regression/) | Linear and regularised regression on bank data, with simulation. |
